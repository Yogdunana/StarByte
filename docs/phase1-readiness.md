## 实测（本环境）

基础设施：PostgreSQL `starbyte_dev`、Redis、MinIO。后端 `APP_ENV=dev`、`go run ./cmd/server`。前端 Vite `:5173`。账号 `admin` / `admin123`。

### 探针

- `GET /health` → 200，`status=ok`（含 uptime / version）
- `GET /health/ready` → 200，database + redis + minio 均为 ok
- `GET /metrics` → 200，Prometheus 文本
- `GET /swagger/index.html` → 200（非生产）

### API（登录后，间隔请求避免用户令牌桶 429）

全部 `code=0`：`/auth/me`、用户、通知、入会申请/档案、面试场次、会议、任务、实习列表/我的/排行、流程定义/实例/待办、统计 overview/providers、表单、文件、角色、权限树、部门、审计、字典 types、运行时配置、调度任务、搜索 resources、缓存 stats、导出 templates、在线会话、通知模板、邮件发送记录。

连续打 30+ 个接口会触发 #75 用户限流（约 2 req/s、burst 10），浏览器正常点菜单不会。

### 浏览器

工作台、入会申请、会员档案、面试安排、会议列表、任务列表、实习记录、流程设计器、统计概览、动态表单、文件（空表）、审计、部门均能打开，无白屏、无持续 loading、无 500 toast。

占位：`/workflow/instances`、`/workflow/todo`、`/system/role`、`/system/permission` 显示「开发中」。对应 REST 已可用，只是没有管理页。

## 文档里修过的错

- README 一期表仍写「规划中」——已改成当前状态
- 本地启动应使用 `deploy/docker-compose.dev.yml`（生产 compose **不暴露** 5432/6379）
- 后端应 `go run ./cmd/server`，不能只 `go run cmd/server/main.go`（同包还有 swagger/traffic）
- 生产前端映射是 **80**，开发 Vite 是 **5173**；Swagger 已接入
