## 建议联测顺序

1. 新注册账号：只有 User；个人中心可打开，不能进入角色管理、文件管理或其他业务模块。能查看章程、允许的公告，并申请成为会员或干事。
2. CMS：分别设置 User 可见、member 可见文章；用两个账号检查列表、搜索与详情的访问限制。通用文件接口仍不向 User 开放，不应把受保护附件的通用下载作为已实现功能。
3. 管理员账号：确认 admin 不再是会长。在角色成员页为真实测试人员登记会长、部长、中心主任/副会长；不同职务分别选择范围，验证兼职不会覆盖前一项任命。
4. 新默认审批：会员走综合行政部初审、所属中心复审、常委会会签；干事按申请部门审核，先完成对应轮次面试。兼任者可在不同阶段分别签字，同一会签节点每人只计一次。已自定义的流程按原图保留，需先核对再决定是否发布新模板。
5. 候补期：未到期或有待处理异议时不能转正；到期后由直属部长在正式审批面板确认。自动调度只提醒，不自动授予正式身份。
6. 新加权投票：兼任会长/部长只取最高 2，中心主任/副会长取 1，部长/副部长取 0.5，干事取 0.25。历史冻结投票不重算，自定义配置不自动覆盖。
7. 界面：中文、英文、俄文下检查角色表格、任命弹窗与审批步骤。手机从账号菜单切换语言；表格在自身区域横向滚动，页面主体不应横向溢出。暂时无法读取流程进度时显示重试提示，不显示臆造的旧审批链。
