# 计协章程与系统职务

源文件：[`smbu-ca-charter.html`](./smbu-ca-charter.html)。公开页：`/docs/association-charter`（前端静态 HTML），介绍页：`/about-us`。

章程组织岗（第二十条、第五十六条）与产品口径对齐：会长、副会长、中心主任、副中心主任、部长、副部长、正式干事、会员、预备成员；另有指导老师、荣誉会员、队长/队员。会长不是系统管理员。内部角色编码（`president` / `probationary` 等）保持不变，见 Issue #200。

产品口径（招新与界面优先用这一套，不改 000073 任命模型）：

| 协会角色 | 说明 |
|------|------|
| 会员 | 不隶属任何部门 |
| 预备干事 / 正式干事 | 干事通道：面试 → 正式签字 → 预备干事 → 正式干事 |
| 副部长 / 部长 | 职能部门 |
| 副中心主任 / 中心主任 | 三大中心；副中心主任已写入章程，系统角色编码仍待补 |
| 副会长 / 会长 | 会长 ≠ 系统管理员 |
| 指导老师 / 荣誉会员 | 特殊身份，不在 T1–T7 日常层级 |
| 队长 / 队员 | 技术团队兼职，不是第八个部门 |

系统另有 `super_admin`（系统管理员）。一人可同时担任会长和部长。常委会、会员大会、纪监委、功能型团支部、技顾委一期未单独上线，见 Issue #199。手机短信验证码见 Issue #198。

产品约定（RC-20260906-001）：未来部门仍会设副部长。系统预留：

| 编码 | 名称 | 说明 |
|------|------|------|
| `vice_minister` | 副部长 | 正式职务与角色编码 |
| `deputy` | 副部长（别名） | 仅加权投票配置兼容旧 key |

权限：本部门 `department` 范围，低于部长（可读 + 部分创建，不能完成/删除他人实习）。加权投票默认权重与部长同档 0.5。

实习开关「部长/副部长可改」对部门范围内的部长、副部长同样生效。

## 三大中心与七大部门

种子幂等写入（RC-20260906-002）。旧四部（`tech` / `activity` / `publicity` / `liaison`）原地改码改名并挂到中心下，UUID 不变。

| 编码 | 名称 | 上级 | 说明 |
|------|------|------|
