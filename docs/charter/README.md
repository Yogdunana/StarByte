# 计协章程与系统职务

源文件：深圳北理莫斯科大学计算机协会章程（见同目录 HTML）。

章程组织岗（第二十条、第五十六条）写的是：社长、副社长、中心主任、部门负责人（部长）、干事、正式成员、候补成员。**没有单列副部长。**

产品约定（RC-20260906-001）：未来部门仍会设副部长。系统预留：

| 编码 | 名称 | 说明 |
|------|------|------|
| `vice_minister` | 副部长 | 正式职务与角色编码 |
| `deputy` | 副部长（别名） | 仅加权投票配置兼容旧 key |

权限：本部门 `department` 范围，低于部长（可读 + 部分创建，不能完成/删除他人实习）。加权投票默认权重 2，低于部长的 3。

实习开关「部长/副部长可改」对部门范围内的部长、副部长同样生效。

## 三大中心与七大部门

种子幂等写入（RC-20260906-002）。旧四部（`tech` / `activity` / `publicity` / `liaison`）原地改码改名并挂到中心下，UUID 不变。

| 编码 | 名称 | 上级 | 说明 |
|------|------|------|------|
| `center_rd` | 技术研发中心 | （根） | 副社长兼任主任 |
| `center_ops` | 运营管理中心 | （根） | 副社长兼任主任 |
| `center_ext` | 对外合作中心 | （根） | 副社长兼任主任 |
| `innovation` | 创新创业部 | 技术研发中心 | 大创、孵化、竞赛培训 |
| `project` | 项目开发部 | 技术研发中心 | 软件开发、代码规范、技术资产 |
| `curriculum` | 课程研发部 | 技术研发中心 | 课程体系、教学、课程库 |
| `admin` | 综合行政部 | 运营管理中心 | 招新、档案、换届、内部协调 |
| `brand` | 品牌传播部 | 运营管理中心 | 品牌、新媒体、物料 |
| `strategy` | 战略关系部 | 对外合作中心 | 对外合作、赞助、厂商 |
| `events` | 赛事运营部 | 对外合作中心 | 竞赛组织、活动、学术交流 |

入会申请、面试场次、任务表单的部门下拉只列出七大职能部门，不把中心当作意向部门。
