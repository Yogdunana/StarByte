# 网页 SMTP 密码

首次使用网页保存密码前，在部署使用的环境文件中设置 `STARBYTE_CONFIG_ENCRYPTION_KEY`。使用 `openssl rand -base64 32` 生成独立密钥，妥善保存，然后重新创建 backend 容器使环境生效。不要复用 JWT 密钥。密钥需要与数据库备份一起安全保管；不要随意更换。

在系统配置的 SMTP 页面输入密码并保存，然后发送测试邮件。留空保留现有密码；密码不会回显。网页保存的密码优先于原有 `STARBYTE_SMTP_PASSWORD` / `SMTP_PASSWORD`，尚未保存网页密码的部署继续使用原设置。

数据库及配置缓存只保存 AES-256-GCM 密文。通用配置接口不能覆盖 SMTP 设置，也不返回密文。若密钥丢失或改变，邮件发送会失败；恢复原密钥，或在新密钥下重新输入密码保存。测试按钮使用已经保存的配置。
